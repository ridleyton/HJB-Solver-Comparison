\section*{Data availability}

\emph{Code and derived results.} All code, the preprocessing manifest, the temporal data splits and
every raw result file behind every table and figure are released
(see the manuscript's Reproducibility section). The repository is archived with a DOI at the time of
publication, and the archived version is the one the paper's numbers were produced with.

\emph{Market data.} The minute-bar data used for the market calibration are vendor data and cannot be
redistributed. The repository instead contains the full preprocessing that consumes them, the
temporal split dates, and the derived quantities the calibration depends on (per-instrument
volatility and the Roll effective spread), so the calibration tables can be re-checked without the
bars themselves.

\emph{Environment.} The neural results were produced with the pinned environment in
\texttt{requirements.txt}; the grid results need no GPU. The verification suite runs on CPU and on a
clean checkout with no market data present.
